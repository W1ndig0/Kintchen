SIRI SHORTCUTS FOR THE KITCHEN HUB (iPhone, Apple Watch, HomePod, CarPlay)
=========================================================================
The shortcut drops a line into your gist as a small "inbox" file. The fridge (next sync) or the cloud brain
(within 15 min) turns it into a locked item and deletes the file. Make a SEPARATE fine-grained token for
Shortcuts (Gists: Read and write only) - it lives inside the shortcut.

"ADD TO THE FRIDGE LIST"
  1. Shortcuts app -> + (new shortcut). Name it: Add to fridge list
  2. Add action "Ask for Input": Input Type Text, Prompt "What do you need?"
  3. Add action "Format Date": Date = Current Date, Date Format Custom, Format String  yyyyMMddHHmmss
  4. Add action "Get Contents of URL":
       URL       https://api.github.com/gists/YOUR_GIST_ID
       Method    PATCH
       Headers   Authorization  =  Bearer YOUR_SHORTCUT_TOKEN
                 Accept         =  application/vnd.github+json
       Request Body: JSON
         files  (Dictionary)
           inbox-siri-[Formatted Date].txt   (Dictionary)      <- type inbox-siri- then insert the Formatted Date variable, then .txt
             content  (Text)  =  [Provided Input]
  5. Done. "Hey Siri, add to fridge list" -> "milk, eggs, bread" (commas make separate items).
     Settings of the shortcut: "Show on Apple Watch" - works from the watch and HomePod too.

SAME SHORTCUT, OTHER POWERS (change only the content text in step 4)
  note: [Provided Input]                    pins a note on the fridge          ("Leave a fridge note")
  timer: [Provided Input]                   starts a fridge timer (minutes)    ("Fridge timer")
  event: 2026-11-20 15:30 Dentist           adds an event (date, optional time, title)
  chore: weekly:2 19:00 Garbage out         repeating chore (0 = Sunday)
  recipe: [Shortcut Input]                  imports a recipe: put this one in the SHARE SHEET
                                            (Shortcut details -> Show in Share Sheet, receives URLs) and
                                            share any recipe page from Safari straight to the hub.

AUTOMATIONS (Shortcuts -> Automation, run immediately)
  - "When I arrive at <grocery store>": Show Notification with the TV/phone app link, or just open the
    Kitchen Hub phone app so the list is right there.
  - "When I leave work": run "Leave a fridge note" with the text  Heading home
  - NFC tag on the fridge door (iPhone 7+): tap the phone on it to run "Add to fridge list".
